# UDP Reliable Data Transfer Simulator

Bu layihə **UDP** protokolu üzərində etibarlı məlumat ötürülməsini (Reliable Data Transfer) simulyasiya edir.

### Xüsusiyyətlər:
* **Stop-and-Wait ARQ**
* **Sliding Window (Go-Back-N)**
* **Network Impairment Simulation** (İtki və Gecikmə)
* **Vizual Dashboard** (Streamlit ilə)
